Contributing to VECTORIUSX

Thank you for your interest in contributing. Contributions help improve the
projects and are appreciated. To make collaboration smooth and effective,
please follow these simple guidelines.

How to contribute

1. Open an issue to discuss significant changes before you start working.
2. Fork the repository and create a branch named `feature/your-feature` or
   `fix/issue-description`.
3. Make changes in your branch. Keep commits focused and atomic.
4. Run existing tests and add tests for new behavior where applicable.
5. Push your branch to your fork and open a pull request against `main`.
6. Describe the change in the PR body and reference any related issues.

Commit and PR guidelines

- Use clear, imperative commit messages (e.g., "Add X feature").
- Include a short description in the PR and a longer description if needed.
- Link related issues with `Fixes #<issue-number>` when the PR resolves an issue.

Code style and tests

- Follow existing code style in the project. If there is no style guide, keep
  code consistent with surrounding code.
- Add or update tests to cover important behavior.
- Ensure tests pass locally before opening a PR.

Communication

- Be respectful and constructive in discussions.
- If your change is large, consider splitting it into smaller PRs.

Need help?

If you have questions or need guidance, open an issue or contact the maintainer
at vectoriusx@gmail.com.
